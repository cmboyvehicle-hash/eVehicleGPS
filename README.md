# แอป e-Vehicle GPS (Android) — แอปแยกสำหรับส่งตำแหน่งรถ

แอปเล็กๆ แยกจากแอป e-Vehicle เดิม ติดตั้งคู่กันได้ ไม่ทับกัน (รหัสแอป `th.ev.gps`)
ส่งตำแหน่งรถทุก 1 นาทีไปแสดงที่หน้าแผนที่ `…/exec?page=map`

## วิธีใช้ (คนขับ)
1. เปิดแอป **e-Vehicle GPS** → เลือกรถที่ขับ (🟢 = อยู่ระหว่างทริป)
2. กด **▶ เริ่มส่งตำแหน่ง** (ครั้งแรกให้กดอนุญาต ตำแหน่ง / การแจ้งเตือน / แบตเตอรี่)
3. เริ่มทริปในระบบ e-Vehicle ตามปกติ (ทำก่อนหรือหลังข้อ 2 ก็ได้)
4. ปิดหน้าจอได้เลย — มีแจ้งเตือน "📡 ส่งตำแหน่ง …" ค้างไว้
5. ปิดทริปในระบบ → แอปหยุดส่งเอง

- ถ้ากดเริ่มแล้วไม่มีการเริ่มทริปในระบบภายใน 60 นาที แอปหยุดเอง
- ระบบรับตำแหน่งเฉพาะรถที่เริ่มทริปแล้ว นอกทริปไม่มีการบันทึก

## สร้าง APK ด้วย GitHub Actions
1. แท็บ **Actions** → *Build e-Vehicle GPS APK* → **Run workflow**
2. รอ ~5 นาที → เปิดงานที่เสร็จ → ดาวน์โหลดไฟล์ในหัวข้อ **Artifacts** (ได้ zip ข้างในคือ `eVehicleGPS.apk`)
3. ทุกครั้งที่แก้ไฟล์ใน repo ระบบจะสร้าง APK ใหม่ให้เอง

## สร้าง APK ด้วย Android Studio
File > Open > เลือกโฟลเดอร์นี้ → Build > Build APK(s) → ไฟล์อยู่ที่ `app/build/outputs/apk/`

## ตั้งค่า (`app/build.gradle`)
- `WEB_URL` ลิงก์เว็บแอป …/exec
- `SEND_INTERVAL_SEC` ส่งทุกกี่วินาที (60)
- `WAIT_TRIP_MAX_MIN` รอเริ่มทริปได้นานกี่นาที (60)
- ออกเวอร์ชันใหม่ ให้เพิ่ม `versionCode`

## กุญแจเซ็นแอป (สำคัญเมื่อออกเวอร์ชันถัดไป)
- ไฟล์กุญแจ `evgps.keystore` อยู่ในโฟลเดอร์ Desktop\eVehicleGPS-android\app บนเครื่อง **ไม่ได้อยู่ใน GitHub**
- ถ้าไม่มีไฟล์นี้ใน repo แอปจะเซ็นด้วยกุญแจชั่วคราว — ทุกครั้งที่สร้างใหม่ต้องถอนแอปเดิมก่อนติดตั้ง
- ถ้าต้องการติดตั้งทับได้ทุกเวอร์ชัน: อัปโหลดไฟล์ `evgps.keystore` เข้าโฟลเดอร์ `app/` ของ repo (ตั้ง repo เป็น Private)

## ฝั่งเซิร์ฟเวอร์ (มีแล้วในเว็บแอป)
- `GET  …/exec?api=vehicles` — รายชื่อรถ + สถานะทริป
- `POST …/exec` `{action:'loc', plate, lat, lng, acc, speed, heading, time}` — รับตำแหน่ง
- เก็บที่ชีต `EV_Location` (ล่าสุดของแต่ละคัน) และ `EV_LocationLog` (ทุกจุด)
